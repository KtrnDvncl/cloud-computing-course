### Analysis Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services, currently featuring over 200 fully-featured offerings. Because they were the first to market, they have developed the most extensive ecosystem of specialized tools for almost every technical niche.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure provides the best integration for organizations already using Microsoft technologies like Windows Server or SQL Server. It allows for seamless single sign-on via Active Directory and offers significant cost savings through the Azure Hybrid Benefit.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform (GCP) is considered the strongest in Artificial Intelligence and Kubernetes. Since Google originally developed Kubernetes, their managed service (GKE) is highly advanced, and their AI tools like TensorFlow and BigQuery are industry leaders.

**4. Which cloud platform would you personally choose and why?**
I would personally choose AWS because of its massive community support and extensive documentation. As a student, having access to the most tutorials and a widely recognized certification path makes it the most practical platform to master first.
