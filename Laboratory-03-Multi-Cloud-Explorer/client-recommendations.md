# Cloud Platform Recommendations

### Client A – Startup Company
*   **Recommended Platform:** Amazon Web Services (AWS)
*   **Justification:** AWS is an ideal choice for startups because of its "pay-as-you-go" pricing model, which helps manage a limited budget. It offers incredible scalability through Auto Scaling, allowing the application to grow seamlessly as the user base increases. Additionally, the AWS Activate program provides startups with free credits and technical support to get started quickly.
*   **Services to Use:** Amazon EC2 (for hosting), Amazon S3 (for storage), and AWS Amplify (for rapid mobile app development).

### Client B – University
*   **Recommended Platform:** Microsoft Azure
*   **Justification:** Since the university already relies on Windows Server, Microsoft 365, and Active Directory, Azure is the most logical choice. It provides native, seamless integration with their existing software stack, making the migration process much smoother. The university can also use Azure Active Directory to manage student and faculty identities across both on-premise and cloud environments.
*   **Services to Use:** Azure Virtual Machines, Azure Active Directory, and Azure SQL Database.

### Client C – AI Research Company
*   **Recommended Platform:** Google Cloud Platform (GCP)
*   **Justification:** GCP is the industry leader when it comes to high-performance computing for Artificial Intelligence and Machine Learning. Their specialized hardware, like Tensor Processing Units (TPUs), is specifically designed to handle the complex mathematical calculations required for AI research. Furthermore, Google’s BigQuery tool allows for incredibly fast analysis of the massive datasets often used in research.
*   **Services to Use:** Vertex AI, BigQuery, and Google Compute Engine (with GPU/TPU support).

### Client D – Global E-Commerce Company
*   **Recommended Platform:** Amazon Web Services (AWS)
*   **Justification:** AWS was built to power Amazon.com, the world's largest e-commerce site, so it is perfectly suited for this scenario. Its massive global infrastructure ensures that customers around the world experience low latency. With features like Amazon CloudFront and Multi-Region deployments, the company can guarantee high availability and automatic scaling during peak shopping seasons like Black Friday.
*   **Services to Use:** Amazon CloudFront (CDN), Amazon Aurora (Global Database), and AWS Auto Scaling.
