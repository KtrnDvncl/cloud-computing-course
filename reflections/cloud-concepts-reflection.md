# Cloud Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use depend on it. Three cloud services that I regularly use are Messenger, GCash, and Netflix. These applications make communication, online payments, and entertainment more convenient because I can access them anytime and anywhere using the internet.

Messenger is an example of **Software as a Service (SaaS)** because it lets users send messages, make voice calls, and video calls without installing or managing servers. It uses the **Public Cloud** deployment model because the service is available to millions of users through the internet.

GCash is also a **Software as a Service (SaaS)** application because it allows users to pay bills, send money, and make online transactions using a mobile app. It also uses the **Public Cloud** because customers can securely access the service online whenever they need it.

Netflix is another example of **Software as a Service (SaaS)** since it provides movies and TV shows through an online streaming platform. Like Messenger and GCash, Netflix uses the **Public Cloud** because its services are available to users around the world through the internet.

Version control is important in cloud projects because it helps keep track of every change made to files. If a mistake happens, previous versions can be restored easily. Git and GitHub also make it easier for people to work together by organizing updates and preventing conflicts when several users are working on the same project. This makes teamwork more efficient and reduces errors.

Through this activity, I realized that cloud computing is already part of my everyday life. It supports many of the services I use daily, while GitHub helps organize projects and makes collaboration easier for students and professionals.
